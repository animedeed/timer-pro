# Журнал разработки Timer Pro

Что делали и зачем — по этапам.

## 1. Оценка и починка исходного таймера
Начальная версия: простой таймер/секундомер на eframe 0.27 с календарём истории и выбором звука.
- Исправили падение календаря в коротких месяцах (`unwrap` на 31-м числе) — добавили тест на все месяцы.
- Звук будильника вшили в exe (`include_bytes!`) — после установки относительный путь не находился.
- Сохранение прогресса идущего таймера при закрытии (`sync()` перед записью).
- Перетаскивание виджета мешало кнопкам и полям — зона drag регистрируется раньше кнопок.

**Зачем:** программа падала и теряла данные — сначала надёжность, потом внешний вид.

## 2. Редизайн v1 по Claude Design
Пользователь сделал макет в Claude Design (`design/Timer Pro.dc.html` + компоненты).
- Переезд на egui 0.36 (нужны `multiply_opacity` для анимаций и иконки Phosphor), рендер glow.
- `theme.rs` — токены макета; `kit.rs` — свои отрисованные кнопки, поля, переключатели.
- Стопка «парящих» блоков: виджет 350×64, плашка «Сейчас играет», меню 350×540, прозрачные зазоры.
- Плашка музыки через системные медиаконтролы Windows (SMTC) — показывает Яндекс Музыку,
  браузер и т. п. Аккаунтный режим Яндекса пользователь отклонил.
- Шрифты Inter и JetBrains Mono вшиты в exe (если лежат в `resources/fonts`).

**Зачем:** пользователю нужен красивый ненавязчивый виджет поверх всех окон, а не обычное окно.

## 3. Окно, мониторы, рамка
- Виджет пропадал/уезжал на трёх мониторах с разным масштабом — перешли на физические пиксели,
  расстановку в первом кадре и проверку попадания на монитор.
- Убрали тень DWM, акцентную рамку и чёрную линию сверху (обработка `WM_NCCALCSIZE`).
- Плашку музыки можно перетащить над/под виджетом; настраиваемый зазор между блоками.

**Зачем:** без этого виджет то не появлялся, то «полз» на пару пикселей при каждом запуске.

## 4. v2: перемотка, бегущая строка, хоткеи, трей, уведомления
По второму макету (`design/Timer Pro v2.dc.html`), новая вкладка «Система».
- Полоса перемотки трека, бегущая строка для длинных названий.
- Глобальные горячие клавиши с записью сочетаний, включая медиаклавиши и цифровой блок.
- Значок в трее с меню, «крестик сворачивает в трей».
- Уведомление Windows, когда таймер дошёл до нуля (понадобился ярлык с AUMID в меню «Пуск»).
- Мелодия будильника играет один раз, а не по кругу; идущие таймеры продолжают считать после перезапуска.

**Зачем:** управлять таймером и музыкой, не трогая виджет, и не пропускать окончание таймера.

## 5. Голосовое управление «Джарвис»
- Выбрали офлайн Vosk (маленькая русская модель, ~140 МБ с библиотекой): без облака и аккаунтов.
  Проверили на синтезированных фразах, что модель знает слово «джарвис».
- Захват микрофона, слово-активатор, разбор команд: музыка, таймеры с длительностью и названием
  («таймер на полтора часа чтение»), секундомер, пауза/стоп, «тихо», окно.
- Команды сначала «не работали» — программа слушала молчащий микрофон по умолчанию. Добавили выбор
  микрофона, индикатор уровня и строку «Услышано» с любой распознанной фразой.
- «Слушаю…» в виджете с пульсацией обводки, отклик на 3 секунды после команды.

**Зачем:** управлять таймерами и музыкой голосом, не отвлекаясь; в будущем — управление ПК (запуск программ).

## 6. Заметки
По опросу пользователя: панель слева от виджета, заметка = задача с чек-листом, напоминания
разовые и повторяющиеся, создание голосом.
- Панель шириной с виджет, по высоте до низа меню; если слева нет места — справа.
- Галочки, чек-листы с прогрессом, описание, папки (заметка может быть в нескольких, клик ставит/снимает),
  перенос чипов папок по строкам, сортировка через выпадающее меню, поиск, раздел «Выполнено».
- Напоминания задаются словами («завтра в 9», «через 20 минут», «по будням в 10») — общий разбор
  для поля ввода и голоса; при срабатывании — тост, пульс виджета, строка «Напоминание · …».
- Голос: создание заметок и напоминаний, папки (создать/удалить/переименовать/положить/убрать),
  удаление таймеров. Затем — работа с пунктами внутри заметки: «в заметке курсовая отметь контрольное»,
  «текущая заметка» (раскрытая или последняя упомянутая) и уточнение, если пункт есть в нескольких заметках.
- Поля карточки (название, описание, пункты) растут по высоте под длинный текст.

**Зачем:** держать задачи рядом с таймером и управлять ими голосом; пользователь сразу нашёл
неоднозначности (одинаковые пункты в разных заметках) — их решили явной областью «в заметке …» и контекстом.

## 7. Публикация
- git (раньше пользователь от него отказывался — понадобился для GitHub), публичный репозиторий
  `animedeed/timer-pro`, лицензия MIT, README, список сторонних компонентов.
- Модель Vosk не хранится в git — скачивается `scripts/get-vosk.ps1`.
- Установщик Inno Setup: для текущего пользователя без прав администратора, русский язык, обновление поверх.
- GitHub Actions собирает установщик и публикует релиз по тегу `v*`. Первая сборка упала: скрипт
  скачивания модели с кириллицей был без BOM, и Windows PowerShell не смог его разобрать.

**Зачем:** выложить программу для других и выпускать новые версии одной командой.

## Возможные следующие шаги (обсуждались)
- Выбор времени напоминания кнопками (как в таймере) рядом с вводом текстом.
- Свои голосовые команды «фраза → программа/ссылка» для управления ПК.
- Большая модель Vosk (~1,8 ГБ) для лучшего распознавания названий.
