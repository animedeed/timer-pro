# Timer Pro

Плавающий виджет-таймер для Windows: таймеры и секундомеры, история, заметки с напоминаниями, управление музыкой и **офлайн-голосовой помощник «Джарвис»** на русском языке.

Тёмные «парящие» блоки без рамки окна, всегда поверх остальных окон, не мешают работе.

**[⬇ Скачать установщик для Windows](../../releases/latest)**

## Возможности

- **Таймеры и секундомеры** — сколько угодно одновременно, закреплённый показывается в виджете. Идущие таймеры продолжают считать после перезапуска программы.
- **История** — календарь с сессиями по дням и общим временем.
- **Заметки-задачи** — панель слева от виджета:
  - галочки «выполнено», чек-листы с прогрессом, описание;
  - папки (заметка может быть в нескольких), сортировка, поиск;
  - напоминания: разовые и повторяющиеся (каждый день, по будням, раз в неделю), время пишется словами — «завтра в 9», «через 20 минут», «каждый понедельник в 12».
- **«Сейчас играет»** — плашка с треком из Яндекс Музыки, браузера и других плееров (системные медиаконтролы Windows): пауза, перемотка, следующий/предыдущий трек.
- **Уведомления Windows**, когда таймер закончился или сработало напоминание.
- **Глобальные горячие клавиши** (настраиваются, поддерживаются медиаклавиши и цифровой блок) и **значок в трее**.
- **Голосовое управление «Джарвис»** — полностью офлайн, ничего не отправляется в интернет.
- **Громкость плеера голосом** — меняется громкость именно той программы, где играет музыка (браузера, Spotify, Яндекс Музыки) в микшере Windows, а не системная.

## Голосовые команды

Сначала скажите «Джарвис», затем команду — одной фразой или после короткой паузы.

| Что | Как сказать |
|---|---|
| Музыка | «пауза», «играй», «дальше», «следующий трек», «назад» |
| Громкость плеера | «громче», «тише» (±10 %), «громче на 20», «громкость 30», «громкость на максимум», «выключи звук», «включи звук» |
| Перемотка | «на 10 секунд назад», «вперёд на минуту», «перемотай назад», «трек сначала» |
| Таймер | «поставь таймер на 25 минут работа», «таймер на полтора часа чтение», «засеки 10 минут» |
| Секундомер | «запусти секундомер обед» |
| Управление | «поставь таймер на паузу», «продолжи таймер», «останови таймер», «удали таймер чай», «тихо» |
| Заметки | «заметка купить молоко», «запиши в папку работа подготовить отчёт» |
| Напоминания | «напомни завтра в девять позвонить Ивану», «напомни через 20 минут проверить духовку», «напоминай каждый день в восемь выпить таблетки» |
| Пункты | «открой заметку покупки», «добавь пункт хлеб», «в заметке МИНОВ отметь контрольное», «сними отметку с хлеб», «удали пункт сыр» |
| Папки | «создай папку учёба», «положи заметку отчёт в папку работа», «перенеси отчёт в папку учёба», «покажи папку работа» |
| Окно | «покажи заметки», «скрой виджет», «открой меню» |

Голос включается в **Меню → Система → Голос**. Там же выбирается микрофон, видно уровень сигнала и что именно услышала модель.

## Установка

1. Скачайте `TimerPro-…-Setup.exe` со страницы [Releases](../../releases/latest).
2. Запустите — установка идёт для текущего пользователя, права администратора не нужны.
3. Windows SmartScreen может предупредить о неизвестном издателе (установщик не подписан): «Подробнее» → «Выполнить в любом случае».

Данные (таймеры, история, заметки, настройки) хранятся в `%APPDATA%\myname\TimerPro\data`, папку можно сменить в настройках.

## Сборка из исходников

Нужны [Rust](https://rustup.rs/) (stable, MSVC) и Windows 10/11.

```powershell
# 1. Голосовая модель и libvosk (~140 МБ, в репозиторий не входят)
powershell -ExecutionPolicy Bypass -File scripts\get-vosk.ps1

# 2. Сборка и тесты
cargo test
cargo build --release

# 3. Установщик (нужен Inno Setup 6: winget install JRSoftware.InnoSetup)
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" setup.iss
# → installer\TimerPro-<версия>-Setup.exe
```

Без шага 1 программа тоже собирается и работает — просто голосовое управление сообщит, что модель не найдена.

Служебные режимы для отладки: `timer_pro.exe --test-toast` (проверка уведомлений), `--voice-test <папка с wav>` (распознавание файлов), `--voice-listen 20` (живой микрофон), `--volume-list` (программы в микшере громкости).

### Устройство

| Модуль | Что внутри |
|---|---|
| `src/app.rs` | Окно, блоки виджета, меню, панель заметок, геометрия окна |
| `src/kit.rs`, `src/theme.rs` | Свои виджеты и дизайн-токены (макеты — в `design/`) |
| `src/timer_logic.rs` | Таймеры и секундомеры |
| `src/notes.rs` | Заметки, папки, напоминания, разбор времени («завтра в 9») |
| `src/voice.rs` | Vosk через FFI, захват микрофона, разбор голосовых команд |
| `src/media.rs` | Системные медиаконтролы Windows (SMTC) |
| `src/volume.rs` | Громкость программы-источника музыки в микшере Windows (Core Audio) |
| `src/system.rs` | Горячие клавиши, трей, уведомления |

Интерфейс — [egui](https://github.com/emilk/egui) с рендером OpenGL и прозрачным окном без рамки.
