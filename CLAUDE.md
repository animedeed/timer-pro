# Timer Pro — заметки для Claude Code

Плавающий виджет-таймер для Windows на Rust: таймеры/секундомеры, история, заметки с напоминаниями,
плашка «Сейчас играет», горячие клавиши, трей, уведомления и офлайн-голос «Джарвис».
Репозиторий: https://github.com/animedeed/timer-pro (MIT). История разработки и причины решений — в `docs/DEVLOG.md`.

## Как работать с пользователем
- Пишет по-русски — отвечать по-русски. Комментарии в коде тоже на русском.
- **Отдавать полный код и ничего не выкидывать** из существующей логики при переписывании.
- Правки вносить без запроса разрешения; перезапускать приложение после правок можно.
- **Интерфейс проверяет сам пользователь.** Не кликать мышью скриптами: три монитора с разным
  масштабом, клики промахиваются в чужие окна. Скриншот только для чтения — допустим
  (процесс должен быть per-monitor DPI aware: `SetProcessDpiAwarenessContext(-4)`).
- Стиль UI: тёмные «парящие» блоки без рамки окна, прозрачные зазоры между ними.
- Отказался (не предлагать снова): помодоро-циклы, компактный режим, автозапуск,
  расширенная статистика, аккаунт/API Яндекс Музыки (только SMTC), голосовые ответы TTS (пока).

## Команды
```powershell
powershell -ExecutionPolicy Bypass -File scripts\get-vosk.ps1   # модель Vosk + libvosk → resources\vosk (не в git)
cargo test                                                     # 50+ тестов: разбор команд, время, таймеры, календарь
cargo build --release
powershell -ExecutionPolicy Bypass -File scripts\package.ps1   # → installer\TimerPro-<ver>-Setup.exe и -portable.zip
```
Отладочные флаги exe: `--test-toast`, `--voice-test <папка с wav>`, `--voice-listen <сек> [имя микрофона]`, `--volume-list`.

Перед `cargo build --release` приложение надо закрыть (exe занят). Если оно свёрнуто в трей,
`CloseMainWindow` не работает (окна нет) — завершать процесс; таймеры не теряются
(`running_since_ms` + автосохранение раз в 30 с).

## Релиз
Версия — в `Cargo.toml` (`scripts\package.ps1` передаёт её в `setup.iss`). Описание релиза —
`.github/release-notes/vX.Y.Z.md`. Затем `git tag -a vX.Y.Z -m … && git push origin vX.Y.Z` —
GitHub Actions (`.github/workflows/release.yml`) скачивает модель, гоняет тесты, собирает
установщик и публикует релиз. `gh` не авторизован (device-code вход у пользователя не прошёл);
`git push` работает через Git Credential Manager. Статус сборки — публичный API
`api.github.com/repos/animedeed/timer-pro/actions/runs`.

Картинки README (`docs/screenshots/*.png`) — не снимки экрана, а `docs/screenshots/showcase.html`
(вёрстка по токенам с демо-данными), снятая Edge без окна: `msedge --headless=new
--force-device-scale-factor=2 --default-background-color=00000000 --window-size=W,H
--screenshot=<png> "file:///…/showcase.html?scene=hero|notes|voice"` (размеры 778×744, 422×750, 422×440).
Настоящие скриншоты с экрана пользователя не публиковать — там личные заметки.

## Устройство
| Файл | Что внутри |
|---|---|
| `src/main.rs` | Запуск, AUMID для уведомлений, отладочные флаги, окно (прозрачное, без рамки, `with_resizable(false)`) |
| `src/app.rs` | `TimerApp`: стопка блоков (виджет, плашка музыки, меню, панель заметок), геометрия окна, вкладки, голос, напоминания |
| `src/kit.rs` | Самописные виджеты с абсолютной раскладкой: `button` + `ButtonStyle`, `toggle_row`, `hms_field`, `text_trunc`… |
| `src/theme.rs` | Дизайн-токены из `design/*.dc.html`: цвета, размеры, радиусы, длительности анимаций, шрифты |
| `src/timer_logic.rs` | `TimerInstance`: таймер/секундомер, `sync()` перед сохранением, `resume_after_load()` |
| `src/notes.rs` | Заметки, папки, `Reminder` (Once/Daily/Weekdays/Weekly), `parse_when` («завтра в 9»), нечёткий поиск |
| `src/voice.rs` | Vosk через `libloading` (FFI), захват микрофона cpal → 16 кГц, «Джарвис», `parse_command` |
| `src/media.rs` | SMTC (`Windows.Media.Control`) в фоновом потоке: снимок трека (`source_id` = AUMID), команды, перемотка (`SeekBy` от текущей позиции) |
| `src/volume.rs` | Громкость программы-источника в микшере Windows (Core Audio): поиск по AUMID → exe (`source_matches`), иначе самый громкий активный поток |
| `src/system.rs` | Горячие клавиши (`global-hotkey`) и их запись, трей (`tray-icon`), тосты Windows |
| `src/models.rs`, `src/storage.rs` | `AppConfig`/`AppState` (serde, `#[serde(default)]`), JSON в `%APPDATA%\myname\TimerPro\data` |

`App::logic()` работает и когда окно скрыто (тики таймеров, хоткеи, трей, голос, напоминания);
`App::ui()` — только отрисовка. Всё «живое» класть в `logic()`.

## Грабли, на которые уже наступали
- **Геометрия окна в физических пикселях.** Якорь виджета — `anchor_px`/`widget_pos_px`; точки egui
  зависят от масштаба монитора. Позицию ставить в первом кадре, проверять `MonitorFromPoint`,
  дрожание < 4 px игнорировать. Окно растёт вверх/влево (`above`, `left` в `applied`), виджет стоит.
- **Рамка Windows 11:** в подменённом wndproc `WM_NCCALCSIZE` → 0, `WM_NCACTIVATE` с lParam −1.
  НЕ отключать `DWMWA_NCRENDERING_POLICY` — появляется классическая рамка.
- **egui: порядок регистрации.** Зона перетаскивания регистрируется ДО кнопок (позже добавленный
  виджет выигрывает клик). Строки списка: заголовок-клик до галочки.
- **Окно не менять под курсором по нажатию** — клики по кнопкам терялись; расширять только после начала drag.
- **Тосты Windows** требуют AUMID `TimerPro.Widget` у процесса, в реестре И ярлык в меню «Пуск»
  с `System.AppUserModel.ID` (создаётся при каждом запуске). Первый тост после создания ярлыка может пропасть.
- **Хоткеи с медиаклавишами и нумпадом** ловятся в wndproc при записи (`system::capture`), egui их не видит.
- **Vosk:** `libvosk.dll` грузить с `LOAD_WITH_ALTERED_SEARCH_PATH` (зависимости рядом). Маленькая
  модель знает слово «джарвис». Микрофон по умолчанию может молчать (у пользователя живой — Impulse GMC 600),
  поэтому есть выбор устройства и индикатор уровня.
- **Разбор голоса — чистые функции с тестами** (`parse_command_at` с фиксированным «сейчас»).
  Порядок в `parse_notes_command` важен: папки → пункты → удаление → открыть заметку → панель →
  новая заметка/напоминание → отметка. «в заметке X …» — название до первого слова-действия (`note_scope`).
- **Тексты в полях заметок растут по высоте:** высоты считает `editor_layout` (тот же шрифт и ширина
  переноса, `TextEdit` с `margin(ZERO)`), иначе текст вылезает за поле.
- **Громкость — не системная.** Голосом меняется уровень программы в микшере (у браузера все вкладки сразу).
  Громкость внутри сайта (ползунок music.yandex.ru) так недоступна — только через расширение браузера.
  «тихо» = будильник, «тише» = громкость; голое «назад»/«вперёд» = трек, с временем — перемотка.
- **Конфиги с BOM** — `storage::strip_bom`. **PowerShell-скрипты с кириллицей — сохранять с UTF-8 BOM**,
  иначе Windows PowerShell 5.1 не разбирает их (так упала первая сборка релиза).
- Папка проекта числится за старым SID — для git добавлен `safe.directory`.
- В JS/JSON-правках через bash-heredoc кавычки и `\` ломаются — писать скрипты правок файлами.
