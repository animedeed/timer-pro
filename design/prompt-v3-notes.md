# Промт для Claude Design — Timer Pro v3: заметки и голос «Джарвис»

Приложи к промту `design/Timer Pro v2.dc.html` (там текущие токены, виджет, плашка музыки и меню) — и скриншот текущей панели заметок.

---

Продолжаем дизайн десктопного виджета **Timer Pro** (Windows, Rust/egui). Нужен **v3**: новая панель **«Заметки»** и элементы голосового управления **«Джарвис»**. Всё остальное (виджет, плашка «Сейчас играет», меню с вкладками Таймеры / История / Опции / Система) уже сделано по v2 — его не перерисовывай, только сохрани стиль и покажи рядом для контекста.

## Как устроено сейчас (стиль, который нужно сохранить)

- Тёмная тема, «парящие» блоки без рамки окна: каждый блок — скруглённая карточка на прозрачном фоне, между блоками прозрачный зазор 4–16 px (настраивается, сейчас 4).
- Шрифты: **Inter** (Regular / Medium) для текста, **JetBrains Mono** (Regular / Medium) для цифр и времени. Иконки — **Phosphor** (regular и fill).
- Цвета:
  - фон блока `#1C1E2B`, обводка блока — белый 6 %;
  - поверхности `#22242F` / `#262938` / `#2F3344`, утопленная `#161824`, разделитель — белый 8 %;
  - текст `#E9E9ED` / `#9397AB` / `#6A6E80` / неактивный `#464A5A`;
  - опасность `#FF6B6B`;
  - акцент выбирает пользователь (пресеты `#6478FF #9184D9 #3FB8AF #5BBF6A #E0A84F #E3735E #D96BA8 #8A93A8`), сейчас `#D96BA8`; текст на акценте — светлый или тёмный по контрасту.
- Радиусы: блок 14, крупная кнопка 10, контрол 8, чип 6. Внутренний отступ блока 12.
- Размеры: виджет 350×64, плашка музыки 326×56 (мини 32), меню 350×540.
- Анимации короткие: появление блока 0.20 с (alpha 0→1 и сдвиг 8 px от виджета), скрытие 0.15 с, hover 0.12 с, раскрытие строки 0.18 с.
- Виджет (слева направо): кнопка-блокнот «Заметки» (28×40, ghost; в акценте, когда панель открыта; красная точка 6 px — есть просроченные напоминания), над временем строка-метка с иконкой режима и названием таймера (11 px), крупное время `00:17:02` (Mono Medium 26), кнопки play / stop 40×40, меню 40×40, разделитель, крестик. Виджет перетаскивается за любое место.

## Что нарисовать

### 1. Панель «Заметки»
Отдельный блок **слева от виджета** (справа, если слева нет места на экране), **ширина 350** — как у виджета и меню. **По высоте** — от верха виджета до нижнего края меню настроек (виджет + зазор + плашка музыки + зазор + меню ≈ 64 + 4 + 56 + 4 + 540). Виджет при открытии панели не двигается — окно растёт влево.

Состав сверху вниз:
- **Шапка:** «Заметки» (Medium 15) + счётчик невыполненных (Mono 12, третичный); справа иконки-кнопки 28×28: поиск, сортировка, закрыть. За шапку можно тащить окно.
- **Поиск** (появляется по кнопке): поле 30 px.
- **Папки** — чипы 26 px: «Все N», папки с цветной точкой и счётчиком, «+». **Переносятся на несколько строк** (не прокрутка). Выбранная — в акценте. Правый клик по папке — меню: Переименовать / Сменить цвет / Удалить. Создание и переименование — поле ввода прямо на месте чипа. Цвета папок: `#8B7CF6 #2EC48D #F59E42 #4DA3FF #F06EA9 #C9C24A`.
- **Список заметок** (прокрутка). Строка 36 px на поверхности `#22242F`:
  - галочка 17 px;
  - точки папок — **до трёх: заметка может лежать в нескольких папках**;
  - название (13 px; у выполненной — третичный цвет и зачёркивание);
  - справа напоминание: колокольчик или иконка повтора + «сегодня 18:30» / «завтра 9:00» / «пт 12:00» / «ежедневно 9:00» / «по будням 10:00»; акцентное, просроченное — красное. Если напоминания нет, вместо него прогресс чек-листа «1/3» (Mono 11) и полоска 2 px под строкой.
- **Раскрытая карточка** (клик по строке, обводка в акценте):
  - поле «Название»;
  - поле «Описание» (2 строки);
  - пункты чек-листа: галочка 14, текст, крестик удаления;
  - поле «+ Пункт чек-листа»;
  - блок напоминания — либо поле «Напомнить: завтра в 9, через 20 минут…» с тремя быстрыми чипами «Через 1 ч» / «Вечером» / «Завтра 9:00», либо строка с установленным временем и кнопкой «Убрать» (у просроченного — «· просрочено» красным);
  - чипы папок с **множественным выбором** (клик ставит или снимает; «Без папки» снимает все), с переносом строк;
  - внизу «Создано 22 октября» и «Удалить» (danger-ghost).
- **Раздел «Выполнено · N»** — сворачиваемый, справа «Очистить».
- **Внизу:** поле «Новая заметка…» (36 px) и квадратная акцентная кнопка «+».
- **Пустые состояния:** «Пока пусто / Напишите заметку ниже или скажите «Джарвис, заметка …»», «В этой папке пусто», «Ничего не найдено».
- **Выпадающее меню сортировки** (под кнопкой, ширина 200): заголовок «Сортировка» и пункты с иконками — Сначала новые / Сначала старые / По напоминаниям / По алфавиту / По папкам; выбранный с галочкой. Кнопка сортировки в акценте, если выбран не порядок по умолчанию.

### 2. Напоминание в виджете
Когда срабатывает напоминание: обводка виджета 10 с пульсирует акцентом. Строка-метка над временем на минуту становится «🔔 Напоминание · Позвонить Ивану» (в акценте); клик открывает заметку. Плюс системное уведомление Windows — его рисовать не нужно.

### 3. Голос «Джарвис» в виджете
- Пока слушает — в строке-метке иконка микрофона и «Слушаю…» (акцент).
- После команды — на 3 с отклик: «Таймер «Чай» — 5 мин», «Заметка «Купить молоко» · завтра 9:00», «Не понял: «…»» (третичный).
- Предложи, как сделать «слушаю» заметнее, не увеличивая виджет (например, мягкая пульсация).

### 4. Вкладка «Система» → группа «Голос»
- Переключатель «Голосовое управление «Джарвис»».
- Строка «Микрофон» с чипом-кнопкой названия устройства: клик переключает на следующий микрофон. Лучше предложи выпадающий список.
- Статус: «Загрузка модели…» / «Готов — скажите «Джарвис» и команду» / «Слушаю команду…» / «Ошибка: …».
- Полоска уровня микрофона (4 px).
- «Услышано: «…»».
- Примеры команд (11 px, третичный).

## Что важно
- Панель заметок — главный новый экран: покажи её в состояниях пустая / список / раскрытая карточка / выбрана папка / открыт поиск / открыто меню сортировки / создание папки.
- Покажи всю композицию целиком: панель слева + виджет + плашка + открытое меню справа, с одинаковыми зазорами и нижним краем панели на одной линии с меню.
- Без лишних рамок и теней — «парящие» блоки как в v2.
- Экспорт как раньше: `Timer Pro v3.dc.html` + компоненты (`Notes.dc.html` и обновлённые `Widget` / `Menu`), с токенами, размерами и описанием анимаций в одном файле.
